Responde esta parte en el documento parte_4/parte_4.md. Incluye cada pregunta y su respuesta.
1. Explica la diferencia entre Git y GitHub: La diferencia está en que Git puede guardar y controlar los cambios de mi proyecto en mi computadora, mientras que GitHub permite tener el proyecto en internet.
2. Explica para qué sirve .gitignore. Éste sirve para que Git no tenga archivos o carpetas que no se quieren subir, como el .venv.
3. Explica por qué .venv no debe almacenarse normalmente en GitHub. Ya que contiene otros archivos más pesados y recomendablemente no se hace porque cada persona puede crear su propio entorno virtual en su computadora y en sí no es necesario subirlo al proyecto. 
4. Explica para qué sirve requirements.txt: Sirve para guardar las dependencias de bibliotecas que necesita el proyecto.
5. Explica la diferencia entre Stage, Commit y Push: Que stage, es la preparación de los cambios, en Commit se guardan y en push se suben a Github.
6. Explica por qué un repositorio puede tener varios commits antes de realizar un push. Porque de esa manera se pueden guardar varios cambios en mi computadora antes de subirlos a GitHub.
